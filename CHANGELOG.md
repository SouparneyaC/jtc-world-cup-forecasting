# Changelog

All notable changes are listed here, newest first. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-22

### Added
- Point-in-time Elo ratings (`ratings`)
- Poisson regression of goals on the Elo difference (`glm`)
- Dixon-Coles scoreline grid with a Negative-Binomial option (`goals`)
- Ordered-logit model of win, draw and loss (`outcome`)
- Count-statistic pricing: thresholds, totals and Skellam comparisons (`counts`)
- Brier score and the crowd-compression fit (`scoring`)
- Question-level results tables, group stage to semifinals
- The research paper, architecture and methodology notes, and three decision records
- Unit tests and a GitHub Actions workflow
